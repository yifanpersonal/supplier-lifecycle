# 产品全周期分析可信可视平台——已实现功能报告

## 1. 项目定位

本工程是在第一版供应商产品生命周期网页 Demo 基础上形成的 Qwen 智能分析版本。系统面向采购方和供应商：接收供应商产品资料与采购考核要求，组织产品信息、生命周期、成本、可视化和决策报告五类结果，并为后续接入真实业务数据和校准模型保留接口。

当前工程可以离线演示基础页面、确定性仿真和数据检索；配置阿里云百炼 API Key 后，可进一步调用 Qwen 完成文档理解、工具调用、RAG 检索、图片文字识别、联网资料研究和报告生成。

## 2. 前端已实现功能

### 2.1 整体界面

- 页面名称改为“产品全周期分析可信可视平台”，去除了原“循证”字样与 Logo。
- 左侧采用可横向收起、展开的侧边栏，桌面端和窄屏均提供基础适配。
- 五个模块从上到下依次为：产品信息、产品生命周期仿真、成本分析、产品可视化、决策报告。
- 每个业务模块都设置了独立的大模型分析区，能够显示任务状态、结论、证据引用、警告与失败原因。

### 2.2 产品信息

- 从后台读取已有的鑫豪斯 Excel 数据，展示产品、部件和批次信息。
- 支持按层级展开产品结构，点击部件后查看该部件的详细信息。
- 提供资料上传入口，可对资料分类，并可录入采购方已确认的数值要求。
- 可启动“质量与标准分析”，输出满足、未满足或证据不足三态结论，避免把缺失证据误判为合格。

### 2.3 产品生命周期仿真

- 支持选择部署地点、分析年限和运行场景参数。
- 生成关键部件的性能衰减曲线、预警线、失效阈值、维护事件和时间轴状态。
- 支持拖动时间轴、播放时间演化和切换维护策略。
- 大模型可检索供应商证据，并联网研究寿命模型资料；模型建议只作为“待校准建议”展示，不会在未经确认时静默改写计算公式。

### 2.4 成本分析

- 汇总采购、维护、更换和风险等生命周期成本。
- 支持不同场景快照的成本对比，并标明成本口径。
- 大模型可结合已有计算结果、供应商材料和联网维护费用资料生成解释；缺少可靠价格来源时会明确标为估算或证据不足。

### 2.5 产品可视化

- 提供可拖拽旋转、滚轮缩放、自动旋转和爆炸展示的阀门交互模型。
- 点击模型部件可联动查看部件信息。
- 支持显示供应商上传的产品照片。
- 支持 2:1 全景图片的拖拽、缩放和视角控制，形成接近原场景 Demo 的 360 度交付环境浏览体验。
- 当前内置模型属于演示级参数化示意模型；上传真实 CAD、GLB 或全景素材后可替换为真实资产。

### 2.6 决策报告

- 汇总前四个模块的确定性计算结果和大模型分析结果。
- 可生成包含质量结论、寿命风险、生命周期成本、证据缺口和选择建议的 Markdown 报告。
- 报告必须区分事实、规则计算、联网资料和模型推断，并保留来源编号。
- 候选产品不足时不会强行生成虚假的横向排名，而是提示补充可比较产品。

## 3. Qwen 智能体与工具能力

- 对接 Qwen OpenAI 兼容对话接口，并支持函数工具调用。
- 提供受限的文件列表、文件读取、报告写入、Excel 分析、图片 OCR、知识库检索、联网研究和读取仿真结果等工具。
- 文件访问限制在工程规定的数据目录中，检查路径穿越和符号链接；报告采用新文件写入，默认不覆盖已有报告。
- 智能体设置最大轮次、最大工具调用次数、超时和后台任务队列，防止无限循环阻塞网页。
- 联网结果只接纳模型返回的可验证 HTTP/HTTPS 来源，并缓存研究结果。
- 供应商文档被当作“数据”而不是系统指令，降低文档中恶意提示词影响分析流程的风险。

## 4. RAG 知识库

当前链路包含：资料解析、清洗切分、元数据标注、SQLite 持久化、BM25 检索、Qwen 向量检索、倒数排名融合、Qwen 重排、相邻片段扩展、产品范围过滤和来源引用。

在没有 API Key、向量接口或重排接口暂时失败时，系统会回退到本地 BM25 检索并显示警告，因此基础演示仍可运行。上传新资料后，需要先完成异步解析与建库任务，之后才能用于智能分析。

## 5. 数据与判断边界

- 采购方考核要求必须由采购方以确认过的 JSON 数据提供；示例规则不是新奥的正式验收标准。
- 质量判断采用三态逻辑：符合、不符合、证据不足；只有数值、单位和适用范围均能确认时才进行自动比较。
- 第一版衰减曲线是确定性工程近似，不是经过现场失效数据训练的可靠性模型。
- 大模型找到的寿命模型、维护周期和价格资料不会直接覆盖确定性计算，需由业务人员确认后再版本化为正式参数。
- 当前供应商样本主要支持单产品演示。多供应商、多候选产品的正式排序需要补充相同口径的数据、权重和约束条件。

## 6. 工程可靠性与验证

- 后台任务、文档、索引和分析快照均写入本地持久化目录，服务重启后可以恢复。
- 页面和接口采用同源访问约束，API Key 只从服务端环境变量读取，不发送到浏览器。
- Python 自动化测试共 38 项通过。
- 前端纯逻辑测试共 5 项通过。
- DOM 交互模拟共 12 项通过，覆盖侧边栏、五模块切换、上传弹窗、检索和分析任务入口。
- 已检查工程中不存在硬编码 API Key；打包文件排除了运行缓存、测试数据库和本地 `.env`。

## 7. 尚未完成和后续扩展

- 当前环境没有提供真实百炼 API Key，因此未进行真实 Qwen 账号权限、额度和在线响应质量验收。
- 当前受运行环境限制，未完成真实 Chromium 截图级视觉验收；已完成 DOM 交互模拟，仍建议在本机浏览器进行最终视觉检查。
- 可继续接入正式采购标准库、更多供应商产品、真实故障和维护工单，用于校准寿命与成本模型。
- 可增加 GLB/CAD 模型解析、部件热点标注和真实交付地点全景素材。
- 可增加 RAG 离线评测集、引用正确率、召回率、规则覆盖率和模型成本监控。
- 可增加用户权限、审计日志、对象存储、数据库服务和部署流水线，形成正式生产系统。

## 8. 运行方式

1. 安装依赖：`python -m pip install -r requirements.txt`。
2. 复制 `.env.example` 为 `.env`，填入 `DASHSCOPE_API_KEY`；如只演示基础功能，可暂不配置。
3. 启动：`python -m backend.server`。
4. 浏览器访问：`http://127.0.0.1:8000`。
5. 在“资料与知识库”中上传和分类材料，建立索引后，再从五个模块启动相应智能分析。
