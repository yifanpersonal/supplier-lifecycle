## 运行环境

后端声明的目标是 Python 3.10 及以上。此前 `knowledge.py` 的字典合并运算符和 `runtime.py` 的 `shutdown(cancel_futures=)` 使用了 3.9+ 才有的接口，在 Python 3.8 下会让所有模块分析任务失败。两处已改为向后兼容写法，因此后端在 3.8 上也可运行；3.10+ 仍是推荐与声明的目标版本，发布前应在目标版本上复测。启动时若解释器低于 3.10，`log/app.log` 会给出提示。

## 本机验收清单

1. 安装依赖，复制 `.env.example` 为 `.env` 并填入百炼 API Key。
2. 启动服务并打开页面，确认页面名称、无 Logo、侧边栏顺序和收起/展开符合要求。
3. 打开“产品信息”，确认产品结构、部件详情与批次信息可用。
4. 上传 Excel、PDF、图片和文本资料，确认后台任务完成；建立索引后能检索到带来源的片段。
5. 上传采购方确认的规则 JSON，确认质量判断能区分符合、不符合和证据不足。
6. 修改部署地点和年限并运行仿真，确认曲线、预警线、失效阈值、维护节点和时间轴同步更新。
7. 修改场景后未重新仿真时，确认智能分析不会混用旧结果，并提示先重新计算。
8. 保存多个相同口径场景，确认成本对比图、明细和删除操作正常。
9. 在“产品可视化”中测试旋转、缩放、自动旋转、爆炸视图和部件点击。
10. 上传产品照片和 2:1 全景图片，确认图片及全景交互正常。
11. 分别启动五个模块的 Qwen 分析，确认任务状态、证据来源、警告和失败信息可见。
12. 生成决策报告，确认报告区分事实、计算和推断，且引用编号可在来源面板中对应。
13. 在无 API Key、关闭向量或重排接口时，确认基础页面、确定性仿真和 BM25 回退仍可工作。
14. 在约 390px、1366px 和 1500px 宽度下检查布局、表格滚动、弹窗和图表。
15. 检查浏览器控制台和 `log/app.log`，不应出现 API Key 或供应商敏感正文泄露。日志按 `docs/QWEN.md` 的边界只记录路径与状态，不记录查询串与正文。

正式演示前，至少完成第 1～12 项，并保存一份已通过样例的决策报告。
